# Password System v1.0

A beginner C++ console application created to practice fundamental programming concepts.

## Features

- Login system
- Password verification
- Three login attempts
- Password changing
- Menu selection
- Invalid selection handling

## Concepts Used

- Variables and data types
- Input and output (`cin`, `cout`)
- Conditional statements (`if-else`)
- Switch-case
- While loops
- Increment and decrement operators
- Comparison operators

## Version

This is an educational project developed as part of my C++ learning journey.
